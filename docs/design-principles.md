# 设计原则

以下是 MCP 服务器发布功能时应遵循的粗略准则。请灵活运用。

- **与 Agent 无关的 API**：使用 MCP 等标准。不要锁定到某一个 LLM。互操作性是关键。
- **Token 优化**：返回语义化摘要。“LCP 为 3.2s”胜过 5 万行 JSON。大量数据应放在文件中。
- **小而确定的模块**：给 Agent 可组合的工具（Click、Screenshot），而非魔法按钮。
- **自愈式错误**：返回可操作的错误，包含上下文和可能的修复方法。
- **人机协作**：输出必须同时可被机器读取（结构化）和人类阅读（摘要）。
- **渐进式复杂度**：工具默认应简单（高层操作），但为高级用户提供可选的高级参数。
- **引用优于值**：对于重型资源（截图、追踪、视频），返回文件路径或资源 URI，绝不返回原始数据流。部分 MCP 客户端支持内置处理重型资源，例如直接显示图片。这 _可能_ 是例外。
