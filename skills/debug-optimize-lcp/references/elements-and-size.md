# LCP 的元素与尺寸

## 哪些元素会被纳入考量？

Largest Contentful Paint（LCP）考量的元素类型包括：

- **`<img>` 元素**：对于 GIF 等动画内容，使用首帧呈现时间。
- **`<svg>` 元素内的 `<image>` 元素**。
- **`<video>` 元素**：海报图加载时间或首帧呈现时间，取较早者。
- **背景图**：通过 `url()` 加载背景图的元素。
- **块级元素**：包含文本节点或其他行内级文本子元素。

## 排除非内容元素的启发式规则

基于 Chromium 的浏览器使用启发式规则排除：

- **不透明度为 0** 的元素。
- **覆盖整个视口**的元素（很可能是背景）。
- **占位图**或低熵图像。

## 元素尺寸如何确定？

- **可见区域**：通常是视口内可见的尺寸。延伸到视口外、被裁剪或溢出的部分不计入。
- **图片元素**：取可见尺寸或固有尺寸中较小者。
- **文本元素**：包含所有文本节点的最小矩形。
- **排除项**：外边距、内边距和边框不计入尺寸。
- **归属**：每个文本节点归属于其最近的块级祖先元素。
