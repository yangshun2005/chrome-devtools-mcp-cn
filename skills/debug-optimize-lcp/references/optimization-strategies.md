# LCP 优化策略

## 1. 消除资源加载延迟

**目标**：确保 LCP 资源尽早开始加载。

- **尽早发现**：确保 LCP 资源能在初始 HTML 文档响应中被发现（不是由 JS 动态添加，也不藏在 `data-src` 中）。
- **预加载**：对关键图片或字体使用 `<link rel="preload">` 并配合 `fetchpriority="high"`。
- **避免懒加载**：绝不要对 LCP 图片设置 `loading="lazy"`。
- **获取优先级**：在 `<img>` 标签上使用 `fetchpriority="high"`。
- **同源**：将关键资源托管在同源下，或使用 `<link rel="preconnect">`。

## 2. 消除元素渲染延迟

**目标**：确保 LCP 元素在其资源加载完成后能立即渲染。

- **减少阻塞渲染的 CSS**：内联关键 CSS，延迟非关键 CSS。确保样式表小于 LCP 资源。
- **减少阻塞渲染的 JS**：避免在 `<head>` 中使用同步脚本。内联极小的脚本。
- **服务端渲染（SSR）**：由服务器下发完整 HTML 标记，使图片资源能被立即发现。
- **拆分长任务**：防止大型 JavaScript 任务在渲染期间阻塞主线程。

## 3. 缩短资源加载时长

**目标**：减少传输资源字节所花的时间。

- **优化资源大小**：提供最优尺寸的图片，使用现代格式（AVIF、WebP），压缩图片/字体。
- **地理就近（CDN）**：使用内容分发网络，让服务器更靠近用户。
- **减少争用**：使用 `fetchpriority="high"` 防止低优先级资源抢占带宽。
- **缓存**：使用高效的 `Cache-Control` 策略。

## 4. 降低首字节时间（TTFB）

**目标**：尽快下发初始 HTML。

- **减少重定向**：避免来自广告或短链接的多次重定向。
- **CDN 缓存**：在边缘缓存静态 HTML 文档。
- **边缘计算**：将动态逻辑移至边缘，避免回源请求。
- **往返缓存**：确保页面符合 bfcache 条件。
